# 02 Annual PPI targets, 5-year point forecasts
Status: accepted
Decision: each model forecasts an annual PPI-style index, 5 years ahead, as a point forecast.
Consequences: monthly sources are averaged to annual (a partial current year is excluded or marked). Annual cadence matches the BEA input-output tables. A series from 1986 gives about 40 observations, which limits model complexity.
Not decided: quantile forecasts (P10/P50/P90). The coefficients schema leaves room for them (see 11).
