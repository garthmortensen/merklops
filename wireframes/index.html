About

A Merkle DAG makes every model run diffable and reproducible.

How it works

  1. Every node has a hash of its inputs and its parents' hashes. Change one input and every hash downstream changes.
  2. The root hash fingerprints the whole run. Same root hash, same run.
  3. Different roots? Walk the lineage to the first changed hash. That is the root cause.
